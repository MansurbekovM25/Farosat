# Inson Farosat

Inson Farosat mobil ilovasining boshlang'ich Flutter loyihasi.

## Ishga tushirish

1. Flutter SDK o'rnating.
2. Terminalda ushbu papkaga kiring.
3. Quyidagi buyruqlarni bajaring:

```bash
flutter pub get
flutter run
```

Hozirgi versiyada sinflar bosh sahifasi va pastki navigatsiyaning dastlabki ko'rinishi mavjud. Firebase, to'lovlar, haqiqiy video darslar va administrator paneli hali ulanmagan.
